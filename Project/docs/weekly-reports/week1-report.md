# Báo cáo Tuần 1 - Khởi tạo dự án & Thiết kế cơ sở dữ liệu

## 1. Mục tiêu tuần 1
- Khởi tạo dự án Android Studio với cấu hình Gradle, Java/Kotlin tương thích, Material 3.
- Xây dựng cấu trúc thư mục kiến trúc MVVM.
- Thiết kế cơ sở dữ liệu trên Cloud Firestore và các Data Models.

## 2. Công việc đã thực hiện
- Thiết lập cấu hình Android app (Namespace: `vn.edu.ueh.rtmiue20.project`, Compile SDK 37, Min SDK 26).
- Xây dựng các lớp Model: `User`, `Book`, `Request`, `Comment`.
- Thiết lập kết nối Firebase (Authentication, Firestore, Storage).
- Phác thảo sơ đồ ERD và luồng màn hình ứng dụng (Wireframes).

## 3. Đánh giá kết quả
- Hoàn thành 100% kế hoạch tuần 1. Cơ sở hạ tầng dự án và các thực thể dữ liệu đã sẵn sàng cho giai đoạn phát triển tính năng.
